# Локальные данные проекта

Репозиторий: https://github.com/maxim505885-jpg/SCAN

В Git хранятся исходники, документация, тесты, проверочные скрипты, скриншоты и JSON-снимки результатов. История локального проекта сохранена.

Следующие данные остаются на рабочем компьютере и не входят в резервную копию GitHub:

- `../1.rcs` — исходное облако, 7 196 593 757 байт. Не помещается в обычный GitHub Git; для передачи нужен отдельный файловый архив или объектное хранилище.
- `data/` — SQLite, обработанные облака, проекты, модели и экспорты.
- `data_smoke/` — данные проверочных прогонов.
- `.venv/`, `frontend/node_modules/` — установленные зависимости; восстанавливаются по requirements.txt и package-lock.json.
- `frontend/dist/` — результат сборки интерфейса.
- Логи и кэши.

Исключения определены существующим `.gitignore`. Исходное облако, локальные проекты и базы нужно резервировать отдельно. Они не удалялись и не перемещались при публикации кода.

Порядок установки и запуска описан в README.md.
