# Протокол проверки участка цеха

Дата: 21 октября 2026. Статус: предварительный, эталонная разметка не завершена.

## Подтверждено пользователем

- AutoCAD 2026, установленный Revit 2027.
- Колонны, подкрановые балки, фермы, вертикальные/горизонтальные связи.
- Номинальный шаг колонн вдоль цеха — **6000 мм (6 м)**.
- Исходный RCS остаётся локально.

## Область A

Локальное определение хранится в data/validation/pilot_candidates.json. Технический crop: X=[−65,−45], Y=[35,55], Z по доступному облаку. Это прямоугольная область мировых координат, не выровненный по каркасу подтверждённый пролёт. Границы могут отсекать стержни.

Сначала определить продольное направление независимо по геометрии. Затем сравнивать расстояния между найденными осями вдоль этого направления с номиналом 6 м. Нельзя считать расстояние только по мировому X, принудительно сдвигать оси на сетку или использовать 6 м как уже измеренное расстояние между любой соседней парой кандидатов.

## Эталонная таблица для заполнения

Для каждой проверенной колонны нужны ID, положение оси, верхняя/нижняя отметка, тип сечения и источник проверки. Для балки — опорные точки/ось, отметка, профиль и подтверждение роли. Для фермы — плоскость, пояса и отдельные стержни; для связи — концы и плоскость.

Источники эталона разделяются: независимый полевой замер, существующий чертёж, ручная разметка облака. Номинальный шаг 6000 мм пока не сопровождается независимым полевым замером конкретной пары колонн.

## Метрики

- Ошибка продольного шага: фактическое расстояние между подтверждёнными осями минус 6,000 м, мм.
- Отклонения оси/концов/отметок от эталона, мм.
- Правильный/неверный/неопределённый профиль и роль.
- Пропущенные/ложные/слитые/обрезанные объекты.
- Полнота по каждой группе отдельно; неподтверждённый кандидат не считается верным.

Численные допуски на оси/отметки ещё не согласованы. До их определения отчёт содержит ошибки, а не заявление о соответствии заданной точности.
