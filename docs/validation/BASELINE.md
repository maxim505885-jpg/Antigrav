SQLite quick_check: ok. Согласованная резервная копия через SQLite backup API сохранена в data/validation/database-20261021T013548142241Z.sqlite3. Рабочая БД при экспериментах открывалась mode=ro. Ручные исправления не затрагивались.

В рабочей БД два реальных импорта: 4 млн и 40 млн точек из 297 873 927 исходных. Массивы плотного импорта: positions float32 (40 000 000 × 3), 480 000 128 байт; colors uint8 (40 000 000 × 3), 120 000 128 байт. Это равномерная выборка, а не все исходные измерения.

## Индекс и контроль выборки

Добавлен неизменяемый пространственный индекс, содержащий номера строк исходных NPY. Координаты и цвета не дублируются. Размер rows.npy для 40 млн: около 320 MB. Построение первой версии использует сортировку O(N) по памяти; это не полностью потоковая индексация. Точный пик RAM не измерялся.

Построение на 40 млн строк: 14,047 с в первом замере. Все строки конечные, потерь/прореживания при индексации нет. Область X=[−65,−45], Y=[35,55], Z=[−5,27,10,69] м вернула 4 004 372 строки. Сортированные source_indices последовательного чтения и индекса совпали полностью.

Первый замер с сортировкой ID: linear 3,8573 с, indexed 1,4111 с. Это один локальный замер, зависит от кэша и размера области; не общий benchmark и не гарантированное ускорение всего приложения. Результат хранится в data/validation/index_validation.json.

Инвалидация: смена origin, размера/mtime файла и незавершённый индекс отклоняются. Это защита от обычной замены данных, а не от подмены файла с сохранением его атрибутов.

## Предварительный участок A

Локальные артефакты:

- data/validation/pilot_candidates.png — обзор и три кандидата;
- data/validation/pilot_candidates.json — определения областей;
- data/validation/pilot-A/positions.npy, colors.npy, source_indices.npy — отдельная копия участка с происхождением точек;
- data/validation/pilot-A/recognition.json — результат отдельного прогона без записи в рабочую БД.

Участок A — технический кандидат, не подтверждённый эталонный пролёт. Его границы могут обрезать конструкции, отсутствие элемента в результате не равно отсутствию в цехе.

Первый прогон текущего алгоритма: 4 004 372 точки, 5,732 с распознавания, кандидаты 16 column / 11 slab / 1 beam / 5 brace / 3 truss. Единственная балка помечена floor_beam; crane_girder не найден. Числа являются выходом эвристики, не проверкой точности. Ручных эталонов и согласованных допусков пока нет.

Обзор показывает, что продольная ось цеха повёрнута относительно мировых XY. Дальнейший контроль должен учитывать ориентацию каркаса и не принудительно выпрямлять фактические наклоны.

## Воспроизведение

Из корня проекта в существующем окружении:

```powershell
.venv/Scripts/python.exe scripts/baseline.py
.venv/Scripts/python.exe scripts/pilot_candidates.py
.venv/Scripts/python.exe scripts/index_cloud.py
.venv/Scripts/python.exe scripts/pilot_recognize.py
.venv/Scripts/python.exe -m pytest backend/tests -q -p no:cacheprovider
```

baseline.py при каждом запуске создаёт новую локальную резервную копию. index_cloud.py повторно использует только индекс с соответствующим fingerprint. Незавершённый индекс не перезаписывается автоматически. Скрипты пилота по умолчанию используют конкретный локальный cloud_id, не произвольный проект пользователя.

## Что ещё не завершено

A0 завершён как исходная проверка; пик RAM не измерен. A1: пользователь подтвердил шаг колонн вдоль цеха 6000 мм; это контрольный номинал, не допуск. Эталонные объекты и допуски пока не подтверждены.

A2 частично: индекс и пространственный reader готовы для существующего NPY; добавлена явная опция spatial_index_path в CloudGeometry. Проверка collect_slice на реальном облаке дала одинаковые 322 763 точки слоя и 80 387 точек региона, все отсортированные пары UV совпали. Но linear 0,451 с против indexed 3,580 с для этого широкого тонкого слоя. Поэтому автоматическое включение в API отменено: интерфейс сохраняет прежний быстрый маршрут. Для выбора режима нужны planner и/или другой layout хранения.

Полного импорта всех RCS-точек/официального SDK, отмены и возобновления сборки пока нет. A3–A9 и сшивка FARO не объявлены выполненными.
