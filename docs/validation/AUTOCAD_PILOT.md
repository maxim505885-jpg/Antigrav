# Приёмка чертежей в AutoCAD 2026

Состояние на 21 октября 2026: пакет для ручной проверки подготовлен; визуальная проверка рендера приложения выполнена. Пользователь подтвердил: «AutoCAD не открылся». Следовательно, текущая v3 не прошла даже интерактивное открытие; редактирование/печать и DWG round-trip остаются открытыми. Ранее открывались предыдущие версии пилотных DXF, но их редактирование и печать не проверялись. Проверка использует только сохранённый производный `recognition.json`; исходный FARO `1.rcs` и рабочая база не задействуются.

## Зафиксированная среда и вход

- Установленный `acad.exe`: `C:\Program Files\Autodesk\AutoCAD 2026\acad.exe`.
- Версия файлов программы: `R25.1.164.0.0` (ProductVersion `25.1.164.0.0`). В самом AutoCAD нужно зафиксировать версию из Help → About при интерактивной приёмке.
- Вход: `data/validation/pilot-A/recognition.json`; SHA-256 `b2e4b476a318197d8bb64edeb5cfb497ed57dd27f90958a2ef40c2682943ca0d`.
- Пакет: `data/validation/pilot-A/autocad-review-v3/manifest.json` и соседние DXF/PDF.
- Исходные 16 колонн и 5 подкрановых балок остаются кандидатами без физических меток. Метки вида `C-01`/`G-01` — только удобные временные обозначения этого пакета; в ведомостях сохранены отдельные `candidate-*` ID. Это не физические марки колонн.
- Все 4 DXF прошли `ezdxf audit`: 0 ошибок, 0 исправлений. В обоих черновых листах ведомости содержат соответственно 16 и 5 уникальных candidate ID; все строки имеют статус «КАНДИДАТ». Финальные контроли намеренно пусты, поскольку подтверждённых элементов в источнике нет. Пустой финал — ожидаемое поведение, не пропуск геометрии.
- SHA-256 каждого экспортного DXF/PDF записан в `manifest.json`. Файлы создаются скриптом, который отказывается перезаписывать существующую папку пакета.

## Автоматическое создание и предварительные проверки

Из корня репозитория:

```powershell
$env:PYTHONPATH = 'backend'
.\.venv\Scripts\python.exe -B scripts/prepare_autocad_pilot.py
```

Команда использует каталог `autocad-review-v3`; при уже существующем каталоге она безопасно завершается ошибкой и не заменяет доказательства. Для нового повторного выпуска укажи новый `--out` и сохрани SHA входа/выходов.

Предварительный просмотр PDF можно получить утилитой Poppler:

```powershell
pdftoppm -f 1 -singlefile -png -r 100 data/validation/pilot-A/autocad-review-v3/columns-draft.pdf data/validation/pilot-A/autocad-review-v3/columns-draft-preview
```

Просмотр приложения показал, что длинные подписи ранее слипались у колонн 13–15. Добавлены явные короткие марки, а полный ID оставлен в ведомости; повторный preview показывает читаемые `C-01`…`C-16`. Проверены также марки `G-01`…`G-05` на черновом плане балок и штампы обеих пустых финальных контрольных страниц. Это проверяет рендер PDF приложения, но не отображение AutoCAD.

## Ручной сценарий AutoCAD

Открыть копии/файлы из `autocad-review-v3` в AutoCAD 2026, не открывая исходный RCS:

1. `columns-draft.dxf`: проверить `UNITS`/свойства единиц (метры), положения/повороты, контуры, размерные линии и слои `S2B-*`; приблизить плотную группу C-13/C-14/C-15; проверить, что короткая марка сопоставляется с полным ID в ведомости.
2. `crane_girders-draft.dxf`: сверить пять осевых линий с планом PDF, отметки кандидатов и ведомость.
3. Открыть парные `*-draft.pdf`; сравнить геометрию и печатный лист A3. Убедиться, что печать идёт 100%, без «вписать»; зафиксировать PDF из AutoCAD/Print Preview.
4. Открыть `columns-final.dxf` и `crane_girders-final.dxf`: проверить заметный штамп «ФИНАЛЬНЫЙ ВЫПУСК» и отсутствие объектов/строк ведомости. Это отрицательная проверка: кандидаты не должны попадать в финал.
5. Из `columns-draft.dxf` выполнить `SAVEAS` в новый `data/validation/pilot-A/autocad-review-v3/columns-draft-roundtrip.dwg`; закрыть и повторно открыть DWG. Проверить редактируемость полилиний, текста, размеров, рамки и таблицы, отсутствие потери единиц и геометрии. Не заменять исходный DXF.
6. Записать результат по каждому шагу, build из Help → About, размер листа/масштаб, замечания по кириллице/шрифтам, пути файлов и SHA-256 нового DWG/PDF. Добавить скриншоты из AutoCAD в эту папку и ниже в запись результатов.

## Повторная попытка интерактивного открытия — 21 октября 2026

AutoCAD 2026 удалось запустить через установленное приложение; интерфейс дошёл до домашней страницы «Начало» и список последних файлов загрузился. Открытие подготовленного `columns-draft.dxf` не удалось выполнить: кнопка домашней веб-страницы не предоставила доступной геометрии для нажатия, сочетание `Ctrl+O` не сменило экран, а получение снимка окна завершалось тайм-аутом. По этому сеансу нельзя утверждать, что DXF открыт или проверен. Редактирование, печать и DWG round-trip не выполнялись. Для следующей попытки нужен прямой диалог открытия внутри рабочего чертежа либо устранение зависания домашнего экрана AutoCAD. Исходный `1.rcs` не открывался и не изменялся.

## Предварительная проверка AutoCAD Core Console — 22 октября 2026

COM-открытие не сработало (`CO_E_SERVER_EXEC_FAILURE` при создании COM-сервера; PowerShell не предоставил `Marshal.GetActiveObject`). AutoCAD Core Console W.164.0.0 принял `columns-draft.dxf` в режиме `/readonly` и выполнил `AUDIT`: проверено 400 объектов, найдено 0 ошибок и исправлено 0. Повторный вывод содержит тот же результат; после команды `QUIT` Core Console перешёл к запросу сохранения/формата и не завершился штатно, поэтому остановлен после проверки аудита. SHA-256 до и после сеанса совпадает с manifest (`f592309f614d0f0abc09516d62736e7bebb8400cc736039ca72b39e6d60ffbbe`). При регенерации консоль сообщила замену `LiberationSerif`/`LiberationMono` на `simplex.shx`; кириллицу, ширину подписей и печатный вид нужно проверить визуально в GUI. Core Console является только парсером/предпроверкой и не закрывает интерактивную приёмку AutoCAD.

## Запуск AutoCAD после очистки зависшего процесса — 22 октября 2026

Пользователь подтвердил, что AutoCAD не открыл DXF. С разрешения пользователя был завершён только старый PID 26872: у него не было главного окна, процесс работал около часа и занимал примерно 1 ГБ. Для исключения проблем с кириллическим путём AutoCAD 2026 повторно запущен на отдельной побайтной копии `columns-draft.dxf` в `%TEMP%`; SHA-256 копии совпал с immutable manifest (`f592309f614d0f0abc09516d62736e7bebb8400cc736039ca72b39e6d60ffbbe`). Пользователь подтвердил, что окна или чертежа всё равно нет. Запущенный для этой попытки тестовый процесс завершён; исходный DXF не менялся, DWG не создан. Лицензионные службы работали, но первопричина запуска GUI не установлена. Следующее продолжение требует доступного диагностического окна/журнала; повторять тот же запуск без новых данных нецелесообразно.

Попытка открыть производный `columns-draft.dxf` повторно запустила AutoCAD 2026, но доступная компьютерная сессия по-прежнему не перечислила нативные окна, поэтому видимый чертёж и его читаемость не подтверждены. Повторный запуск Core Console W.164.0.0 с отдельным `SAVEAS`-сценарием остановился до вывода командного протокола и не создал `columns-draft-roundtrip.dwg`; зависший процесс консоли завершён. Исходный DXF не перезаписывался: размер 128645 байт, SHA-256 `f592309f614d0f0abc09516d62736e7bebb8400cc736039ca72b39e6d60ffbbe`, как в immutable manifest.
