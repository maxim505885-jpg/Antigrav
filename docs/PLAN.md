# Intelligent Scan-to-BIM — состояние проекта и план работ

Обновлено: 20 октября 2026. Все «сделано» подтверждено прогонами на реальном облаке
пользователя `1.rcs` (6.70 GiB, 297 873 927 точек) и автотестами, а не заявлено.

Короткая сводка: **работает сквозной маршрут «импорт → 3D → сечение → DXF/PDF/IFC →
распознавание → ручные правки → обучение модели-кандидата»**. Не работают
нейросетевые классы (балки, фермы, лестницы, инженерные сети) и плагины AutoCAD/Revit.

## 2. Что осталось

Порядок — по ценности для инженера, а не по красоте.

### Ближайшее (1–2 недели)

1. **Слить фрагменты в конструкции.** 318 «колонн» и 43 «стены» на 12 500 м² — это
   переразбиение. Нужно: объединение коллинеарных участков стен, склейка колонн
   по этажам в один стояк, привязка элементов к уровням, отбрасывание всего, что
   не имеет опоры хотя бы на 2 этажа. Критерий приёмки: на этом скане число
   колонн падает до порядка сотен осмысленных, и каждая имеет высоту по этажу.
2. **Лестницы и проёмы.** Проёмы находятся анализом разрывов в уровнях; лестницы —
   по наклонным плоскостям в пределах одного уровня. Оба класса обещаны в ТЗ и
   достижимы геометрически, без нейросетей.
3. **DWG через ODA File Converter**, если он лицензирован: сейчас честный 409.
4. **Плотность как первоклассный фактор.** Сейчас плотность только
   предупреждение; надо, чтобы пороги обнаружения масштабировались от неё и
   результат явно помечался «недостаточно данных для тонких элементов».

### Среднее (3–6 недель)

5. **Плагин AutoCAD** (.NET, `accoreconsole` для автотеста): элементы из API →
   нативные полилинии/3D-тела, обновление чертежа, передача правок назад.
   AutoCAD 2026 на этой машине есть — можно проверять по-настоящему.
6. **Плагин Revit** (пилот): уровни, стены, колонны, перекрытия нативными
   категориями; связь с исходными точками через Pset.
7. **ML-этап 1**: отдельное окружение PyTorch, инференс предобученной модели
   семантической сегментации на выборке проекта, сравнение с геометрическим
   базисом на размеченных инженером примерах.
8. **Чертежи по элементам**, а не только по точкам: план по распознанным стенам
   с осями, размерными цепочками и спецификацией.

### Дальше (2–4 месяца)

9. **Дообучение нейросети** на накопленных примерах с тем же контролем качества
   (кандидат → метрики → активация), что уже работает для KNN.
10. **Сервер и совместная работа**: пользователи, роли, аудит, блокировки
    проектов, PostgreSQL вместо SQLite.
11. **Испытания на разных типах зданий** (жилое, промышленное, каркас) и
    калиброванные метрики качества по классам вместо эвристических оценок.
12. **Публичный релиз**: установщик, миграции БД, документация API для внешних
    интеграторов.

## 3. Известные ограничения (не скрывать)

- Плотность текущего проекта — 320 точек/м² плана: тонкие элементы на пределе
  разрешения, поэтому 318 колонн требуют проверки инженером.
- Толщина стен на сетке 0.04 м измеряется с погрешностью до одного шага растра;
  при одном сканированном отребе толщина помечается как ненаблюдённая.
- Плиты: контур измерен, толщина 0.20 м — **допущение**, а не замер.
- Уверенности эвристические, не калиброванные вероятности. В API это указано
  (`confidence_kind: heuristic`).
- RCS читается через недокументированный внутренний API Autodesk; при смене
  версии ReCap чтение может сломаться. Проверочный тест — повторный импорт файла.
- Скриншоты интерфейса в среде разработки не снимаются (webview не композитится),
  поэтому визуальная проверка делалась через состояние WebGL, а не по картинке.

## 4. Как проверить самому

```bash
# сервер
.venv/Scripts/python.exe backend/run.py --port 8000
# интерфейс
cd frontend && npm run build
# тесты
.venv/Scripts/python.exe -m pytest backend/tests -q
# живой маршрут на реальном скане (нужен ReCap)
.venv/Scripts/python.exe scripts/e2e_rcs.py
```

Маршрут для проверки глазами: выбрать проект «Real scan 1.rcs» → облако → вкладка
СЕЧЕНИЕ → «Построить измеренное сечение» → «Экспорт DXF» → вкладка РАСПОЗНАВАНИЕ
→ «Запустить геометрическое распознавание» → подтвердить 4–5 элементов → вкладка
ОБУЧЕНИЕ → «Обучить кандидата» → вкладка ЭКСПОРТ → «Экспорт IFC4».
